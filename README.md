# SIVI Verzuimstandaard: Werkgevers ↔ Arbodiensten (Simulatie)

Dit is een werkend voorbeeld van **Model B**: een afzonderlijke repository voor het specifieke koppelvlak tussen Werkgevers en Arbodiensten.

## Documentatie & Specificaties
De interactieve documentatie wordt automatisch gepubliceerd via GitHub Pages:  
👉 **[Bekijk de live documentatie](https://dma61.github.io/sim-verzuim-werkgevers-arbodiensten/)**

## Voordelen van deze inrichting:
1. **Eigen Issue-tracker:** Arbodiensten en softwarebouwers hebben hun eigen afgebakende meldpunt zonder ruis van de verzekeraarskant.
2. **Water uit de kraan:** Documentatie staat simpelweg in `/docs` en wordt zonder ingewikkelde CI/CD-scripts direct live gezet door GitHub.
3. **Helder eigenaarschap:** Deze repo spiegelt exact 1 officieel SIVI-koppelvlak.
